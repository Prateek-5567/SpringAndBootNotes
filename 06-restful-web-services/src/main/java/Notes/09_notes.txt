# SPRING BOOT ACTUATOR
-provides spring boot production ready features.
- manage and monitor your application in production.

group id : org.springframework.boot
artifact id : spring-boot-starter-actuator 

Provides a number of endpoints : 
* bean : complete list of spring beans in your app
* health : application health information.
* mapings : details around request mapping.
* metrics : application metrics

	  # Exploring Rest Api using HAL explorer.
	                             hypertext application lang.
	   
	1. HAL : simple format that gives you consistent and easy way to hyperlink between resources in your application.
	
	2. Hal explorer : an api explorer for restful hypermedia api using HAL 
						enables your non tech team to play with api's
						
	3. Spring Boot HAL explorer : Auto configures HAL explorer for spring boot projects.
	
	grpID : org.springframework.data
	artifactId : spring-boot-rest-hal-explorer
	
	now goto localhost:8080/ and hit enter - HAL Explorer opens.
	 
	gives real time interation with apis , their response bodies ,and links vgera...
	
	If your api is compeled with HAL you can use HAL explorer to explore the api.
