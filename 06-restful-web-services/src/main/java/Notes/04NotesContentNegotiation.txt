For Same Resource and Same URI diffrent Representations are possible:-
	eg: Diffrent Content Type : XML or JSON etc.
	eg: Diffrent Language : en , hindi , dutch , Cantonese...
	
How can consumer tell the REST API provider what they want : 
	- through content negotiation
	- here consumer and service provider negotiate with each other
	- contracts are signed requirements are noted down.

groupId : com.fasterxml.jackson.dataformat
artifactId : jackson-dataformat-xml

With jackson-dataformat-xml → JSON ↔ XML

It allows Jackson to serialize Java objects to XML and
 deserialize XML to Java objects. 
we can interchange sending or receiving data between XML and
 json using jackson-dataformat-xml Dependency.
